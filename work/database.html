01

담당 업무

NABIC 데이터베이스와 분석·포털 서비스를 관리했습니다. 연구자가 데이터를 등록하고 검증해 분석에 활용할 수 있도록 등록 오류를 확인하고 이용을 지원했습니다.

02

데이터 등록과 서비스 운영

  • NABIC DB 표준화·유지관리
  • 포털·분석서버 서비스 모니터링
  • 사용자 등록과 분석 프로그램 이용 지원
  • 농생명 오믹스 데이터 업로드·등록·검증 오류 확인
  • 등록확인서 발급과 성과인증 업무 지원
03

데이터 품질관리

  • 파일형식 판별과 메타데이터 구성
  • 데이터 위치·상태·이력 관리
  • 품질평가와 오류탐지
  • 표준어휘 DB 관리
04

분석환경 지원

등록·검증 과정에서 발생한 이용자의 문제를 확인하고, 데이터베이스·포털 관리와 분석서버 지원을 함께 수행했습니다.

05

마이크로바이옴 데이터뱅크 연구

농생명 마이크로바이옴 데이터뱅크 공공 서비스 개발 과제에 참여했습니다. 아래는 공동저자로 참여한 2026년 학술대회 발표자료의 서비스 구조도입니다. BioProject–BioSample–SRA 등록, 표준 메타데이터, HPC 분석과 결과 제공 흐름을 담았습니다.
