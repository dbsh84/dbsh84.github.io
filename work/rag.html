01

구축 목표

디지털·스캔·혼합 PDF를 검색에 쓸 수 있는 텍스트로 정제했습니다. 한·영 표현 차이와 전문용어 때문에 놓치는 문헌을 줄이기 위해 검색 방식을 비교하고 결합했습니다.

02

문헌 정제에서 만난 문제

추출한 수식의 계수와 부호가 원문 화면과 다른 경우가 있었습니다. 숨은 텍스트 레이어와 읽기 순서를 확인하고, 표·위첨자·단위도 함께 검수했습니다. 약 170GB의 원문을 반복 처리해야 했기 때문에 처리 절차와 이력 관리도 정리했습니다.

03

정제와 이력 관리

내장 텍스트의 품질을 먼저 판정하고, 문제가 있는 페이지는 렌더링·OCR로 재처리했습니다. 기호와 수식 표본을 원문 화면과 다시 대조한 뒤 데이터셋에 반영했습니다.

  • 문서 ID·페이지·청크·원본 버전·해시 관리
  • 같은 정제 원천에서 검색용 데이터와 모델 학습용 데이터 생성
04

검색 방식의 선택

한·영 표현 차이는 BGE-M3 의미검색으로 보완하고, 전문용어·품종명·수치의 정확한 일치는 BM25로 찾도록 구성했습니다. 대규모 벡터 검색에는 FAISS를 사용했습니다.

점수 체계가 다른 검색 결과는 Reciprocal Rank Fusion(RRF, 순위 결합)으로 합쳤습니다. 이후 Cross-Encoder로 질문과 상위 후보 문맥의 적합도를 다시 평가했습니다.

05

데이터 규모와 검색 평가

  • 원본 PDF 41,011건 → 검색문서 31,045건
  • 청크·벡터 974,959개 구성
  • 한·영 질의 결합 실험 533문항: Recall@20 31.5% → 57.4%
  • 재정렬 실험 620문항: Recall@10 47.4% → 62.4%
  • 평균 역순위(MRR): 0.2167 → 0.4175
