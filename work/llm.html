01

학습 목표

농업 문헌 기반 RAG를 구축한 뒤, LLM이 검색 근거를 활용해 답변하도록 지속 사전학습(CPT)과 지도 미세조정(SFT)을 설계했습니다. PDF 문헌을 층화·분할하고 LoRA 방식으로 CPT·SFT를 수행했습니다.

도메인·한국어 성능과 함께 실행에 필요한 메모리와 처리량을 비교했습니다.

02

학습·평가 데이터 분리

같은 논문에서 만든 질문과 답변이 학습·평가 세트에 함께 들어가지 않도록 문서 단위로 나눴습니다. 분야·언어별 비율을 고려해 층화하고, 중복과 데이터 누수를 점검했습니다.

03

학습 데이터 구성

정제한 문헌에서 CPT용 원문과 SFT용 질의응답을 만들었습니다. 아래 규모는 해당 학습 버전 기준으로, 후속 데이터 재생성과 별도로 관리했습니다.

  • 논문 단위 학습·검증·평가 분할: 8:1:1
  • CPT: 논문 27,105편 · 약 0.31B 토큰
  • SFT: 논문 26,711편 기반 Q&A 481,968건
04

학습·실행 환경

후보 모델 4종에 공통 LoRA 설정과 평가 형식을 적용했습니다. B200 8장 환경에서 모델 크기와 작업 목적에 맞춰 실행 방식을 구분했습니다.

  • 실행 방식: GPU별 독립 인스턴스 · Tensor Parallel · Distributed Data Parallel
  • 학습: Transformers · TRL · PEFT
  • 모델 서빙·생성·판정: vLLM
05

비교평가

  • 도메인 SFT 성능과 CPT 적응 효과
  • KMMLU 농업 문항 평가
  • 처리량과 메모리 사용량

학습·평가 절차는 표준 작업 절차(SOP)로 정리했습니다. 후속 작업으로 질문·답변 품질 검수와 데이터 재구성을 진행합니다.
