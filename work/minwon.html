01

개발 배경

법령·기술자료·과거 답변과 담당부서 정보를 함께 조회하고, 이를 바탕으로 답변을 작성할 수 있도록 시스템을 개발했습니다. 검색부터 초안 작성, 담당자 검수까지 한 흐름으로 구성했습니다.

02

정보 유형에 따라 검색 경로를 나눈 이유

법령과 기술자료는 비슷한 표현뿐 아니라 정확한 전문용어도 찾아야 했습니다. 반면 담당부서·업무분장은 구조화된 항목을 정확하게 조회하는 일이 중요했습니다. 문헌에는 하이브리드 검색을, 부서 정보에는 관계형 DB 조회를 적용했습니다.

03

주요 구현

  • 문헌 검색: KURE-v1 의미검색 + Kiwi·SQLite FTS5 기반 BM25
  • 검색 결과 정리: RRF 순위 결합 + BGE Reranker
  • 담당부서·업무분장: 관계형 DB 조건 조회
  • 답변 생성: 설치형 LLM에 검색 근거 전달
  • 근거 확인: 답변 출처와 원문 위치 표시
04

담당자 검수

초안을 바로 최종 답변으로 내보내지 않고, 담당자가 확인·수정·승인하도록 Human-in-the-loop(사람의 검수를 포함한 처리 방식)를 적용했습니다.

  • 문의 접수 및 자료·담당부서 조회
  • 검색 근거를 활용한 답변 초안 생성
  • 담당자 확인·수정·승인
  • 최종 답변과 처리 이력 관리
05

구현 결과

검색, 답변 생성, 출처 확인과 검수 화면을 하나의 파일럿 시스템으로 구현했습니다. 검색 결과가 출처와 일치하는지, 초안에 근거가 반영되는지, 담당자가 검수를 마칠 수 있는지 점검했습니다.
