구축 목표

참조 유전체가 충분하지 않은 특용작물의 유전자 정보를 활용할 수 있도록 참조전사체 서열과 기능주석을 정리하고, 조회 가능한 DB로 구축했습니다.

02

서열과 기능주석 연결

  • PacBio Iso-Seq 서열 중복 정리
  • CDS·단백질 예측과 기능주석
  • Gene_ID를 기준으로 Sequence·Annotation 정보 연결
03

MS Access를 선택한 이유

이용자가 복잡한 시스템을 설치하지 않고 서열과 기능 정보를 조회할 수 있도록 MS Access 단일 파일로 DB를 구성했습니다.
