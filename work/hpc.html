유전체 분석과 HPC 운영

슈퍼컴퓨팅 환경에서 유전체 분석을 수행하고, HPC 운영과 분석환경 구성·이용자 지원을 담당했습니다.

01

유전체 분석

슈퍼컴퓨팅 환경에서 유전체 분석을 수행하고, 작업 실행 상태와 SNP·gVCF 등 분석 산출물을 확인했습니다. 분석에 사용한 데이터의 위치와 처리 상태를 함께 관리했습니다.

02

HPC 운영

국립농업과학원 슈퍼컴퓨팅 환경에서 Linux 서버와 CRAY XC40을 운영했습니다. 작업 실행 상태를 확인하고, 사용자 환경과 분석 실행 문제를 점검했습니다.

  • CRAY XC40 · Linux
  • PBS 작업 스케줄러 · ALPS · APRUN
  • 작업 실행 상태 점검과 실행 문제 대응
03

분석환경·이용자 지원

유전체·전사체 분석에 필요한 프로그램과 실행환경을 구성하고, 이용자 교육을 지원했습니다. NABIC 데이터의 형식·메타데이터·위치·상태를 관리하며 분석에 필요한 데이터를 사용할 수 있도록 도왔습니다.

  • 분석 프로그램 설치와 사용자 환경 구성
  • 유전체·전사체 분석 실행환경 지원
  • 교육자료 작성과 실습 지원
04

주요 업무·결과

2026년 분석환경 지원과 교육자료 작성·실습 지원에 참여했습니다.

  • 분석환경 지원: 대내 13건 · 대외 35건 — 공동 지원 실적
  • 이용자 교육: 36명 — 공동 교육 실적
  • 커피속 공공데이터 1,028자원 gVCF 생성 지원
05

작업 관리

분석 데이터가 저장된 위치와 처리 상태, 사용자별 실행환경과 산출물을 함께 확인했습니다. 분석 수행과 환경 운영을 함께 맡으며 작업이 완료된 범위와 이어서 처리할 내용을 관리했습니다.
