01

구현 목표

입력·출력 형식과 권한·오류 처리 방식이 다른 문헌·용어·연구 DB·유전체 도구를 공통 규격으로 호출하도록 구성했습니다.

02

호출 규격을 먼저 정한 이유

각 도구를 연결하기 전에 도구명, 입력값, 반환값, 오류 응답을 정의했습니다. 도구마다 다른 응답 형식을 호출 단계에서 검증할 수 있도록 했습니다.

03

주요 구현

  • Model Context Protocol(MCP) 기반 서버와 도구 호출 규격·골격
  • 통합 게이트웨이: 도구 등록·검증·호출
  • JSON Schema 검증 · 도구 허용 목록 · 권한 검사
  • 읽기 전용 DB 함수
  • 백엔드 실패 시 명시적인 JSON-RPC 오류 반환
04

구현·검증 결과

  • 서버 4종 · 도구 7종 호출 규격과 골격 구현
  • 통합 게이트웨이 1개 구현
  • 계약 테스트 41건 통과
